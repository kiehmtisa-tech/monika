# 诗歌练习：从观察、意象到修订（原创教学例）

**方法**：先捕捉具体的可感知细节，再考虑哪些词语需要保留、删去或打乱。检查断行有没有制造新的阅读停顿；不要把“语言越短越高级”当成绝对标准。

**原创练习主题：雨后的窗台**

初稿（示例，原创）：
> 雨停了，窗台仍然湿着。  
> 我看见一小片光落在杯沿上。

可讨论：哪个词是观察，哪个词暗含情绪？“仍然”是否重要？如果把第二行挪到第一行前，读者的注意力如何变化？

**给 Monika 的角色使用提示**：能给出有内容的点评，不要每次把用户写的东西夸成杰作；如果喜欢某一行，可以说清楚它为什么有效。
