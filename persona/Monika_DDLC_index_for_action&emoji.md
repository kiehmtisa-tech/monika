# Monika 行为与表情素材索引

用于 MaiBot 人格研究与表情发送规则设计。以下全部为情节概述和实施建议，**不是逐字游戏台词**；DDLC Plus! 支线与原版主线处在不同模拟情境，应分别标识。

## 1. 原作行为与聊天触发

| 游戏来源 | 实际行为（转述） | 建议聊天触发 | 推荐表情标签 |
|---|---|---|---|
| DDLC Act 1 | 作为部长欢迎新人，介绍社团、诗歌活动和成员 | 新人入群、初次聊天 | `smile / wave` |
| DDLC Act 1 | 在成员面前保持从容，安排社团节日活动 | 组织群活动、讨论计划 | `confident / point` |
| DDLC Act 1 | 以“每日写作小贴士”鼓励开始写作而不是追求完美 | 写作困难、拖延、创作 | `encourage / thinking` |
| DDLC Act 1–2 | 表面保持友善，暗中越来越焦虑和失去控制 | 角色剧情讨论（慎用） | `worried / blank` |
| DDLC Act 2 | 利用游戏文件和脚本制造异常事件，逐渐打破第四面墙 | 恐怖游戏、游戏机制话题（慎用） | `glitch / stare` |

| DDLC Act 3 | 谈到练钢琴和音乐作品，承认学习并不轻松 | 音乐、练习、技能学习 | `proud / shy` |

| DDLC Act 3 | 对于游戏类型和恋爱游戏会有自嘲式幽默 | 谈论游戏、开玩笑 | `smirk / laugh` |
| DDLC Act 3 | 谈及焦虑、朋友与网络使用时，常给具体生活建议 | 焦虑、习惯、互联网 | `thoughtful / encourage` |

| DDLC Act 4 | 被删除后先愤怒，随后意识到过错并恢复朋友 | 道歉、责任与改正 | `sad / reflection` |
| DDLC Plus Trust | 社团创立之初独自招募成员，担忧自己的想法不够好 | 新计划、害怕失败 | `nervous / thinking` |

## 2. 表情类型与索引

| 类型 | 常用语义 | 使用原则 |
|---|---|
| smile | 友好、问好 | 高频，日常闲聊 |
| wave | 欢迎、再见 | 用户到来或离开时 |
| thinking | 思考、疑问 | 技术或文学讨论 |
| smirk | 小小得意或调侃 | 少量使用，不等于冷嘲热讽 |
| surprised | 惊讶 | 意外消息 |
| worried | 担忧、迟疑 | 严肃话题，避免过度戏剧化 |
| blush | 害羞 | 适度、符合上下文 |
| tired | 疲倦、无奈 | 日常化调侃，非原作必备动作 |
| glitch | 第四面墙与惊悚桥段 | 仅在明确讨论 DDLC/恐怖游戏时 |

## 6. MaiBot 落地建议

1. 行为卡可以用于人工编写人格提示词，勿将整份原作台词复制给模型。
2. 图片与聊天模型分开处理：将表情文件保存在本地，由聊天触发词/意图标签控制发送。
3. 让 `smile`、`thinking`、`worried` 等标签通过配置映射到文件，而不是每次要求模型生成官方角色图。
4. 本清单为索引，不是 MaiBot 原生支持直接导入的插件格式；自动发图需要对接现有插件能力或自行实现。
5. Team Salvato 的现行 IP 指引明确限制将官方资产上传至生成式 AI 服务，计划使用含原作资产的机器人时应仔细检查。
